# MediaGo 在线视频下载工具

基于 m3u8 解析与浏览器扩展的在线视频下载/嗅探/媒体管理 Web 工具。

## 访问

- Web UI: `http://<你的服务器 IP>:<端口>`
- 默认端口: 8899（可通过 1Panel 配置映射到宿主机任意端口）

## 功能

- 浏览器扩展嗅探页面视频，一键推送到服务端下载
- m3u8 视频流解析与合并下载
- 多平台视频内容下载支持
- 下载任务管理：队列、暂停、恢复、删除
- 内置 Web UI 播放器，下载即看
- 下载历史记录与搜索

## 目录结构

```
./data/
├── data/       # 数据库文件
├── logs/       # 日志文件
└── downloads/  # 下载文件存储
```

## 使用

1. 在浏览器安装 MediaGo 浏览器扩展
2. 打开包含视频的页面，点击扩展图标嗅探视频
3. 选择需要下载的视频，推送到服务端
4. 在 Web UI 中查看下载进度与管理任务

## 运行用户 UID / GID

安装参数 `UID` / `GID` 通过 compose 的 `user:` 指定容器内进程身份，默认 `99` / `100`。

⚠️ **首次部署前必须把数据目录属主改到同一 UID / GID**，否则容器无权写入、启动即失败：

```bash
# 以应用实际安装目录为准（1Panel → 应用 → mediago → 详情 → 路径）
sudo chown -R 99:100 <应用安装目录>/data
```

需要 chown 的目录（相对于应用安装目录）：`./data`

- 想以 root 运行：把 `UID` / `GID` 都填 `0`
- 升级到新版本目录后要**重新 chown 一次**（新目录下的 `data` 为空、属主是 root）
- 容器内所有新文件都以该 UID / GID 创建，宿主机上看到属主是 99:100 属正常现象
